# AI Interview Prep Platform

AI-powered interview preparation platform built with Spring Boot, React and Gemini AI.

## Features

- JWT Authentication
- Role-based interview generation
- AI-generated interview questions
- Answer evaluation and feedback
- Dashboard with interview history

## Tech Stack

### Backend
- Java 17
- Spring Boot
- Spring Security
- PostgreSQL
- Gemini AI

### Frontend
- React
- Axios
- React Router

## Run Backend

1. Create application.properties
2. Add database credentials
3. Add Gemini API key
4. Run:

```bash
mvn spring-boot:run
